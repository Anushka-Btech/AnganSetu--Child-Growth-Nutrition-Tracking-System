# ANGANSETU

### Every Child. Every Milestone. Every Day.

ANGANSETU is a digital Child Growth and Nutrition Tracking System designed to support Anganwadi workers in monitoring children's growth, understanding nutrition-related indicators, and managing timely follow-ups.

**TRACK → UNDERSTAND → ACT → FOLLOW UP**

## Key Features

- Child registration and profile management
- Growth monitoring and measurement records
- Nutrition tracking and insights
- Follow-up and notification management
- Dashboard analytics and key indicators
- Worker and administrator interfaces
- Centre-scoped data views
- Local demo data persistence

## Technology Stack

- React
- Vite
- JavaScript
- CSS
- Browser Local Storage

## Getting Started

Prerequisites: Node.js and npm.

Clone the repository:

    git clone https://github.com/Anushka-Btech/AnganSetu--Child-Growth-Nutrition-Tracking-System.git

Navigate to the project:

    cd AnganSetu--Child-Growth-Nutrition-Tracking-System

Install dependencies:

    npm install

Start development server:

    npm run dev

Build for production:

    npm run build

## Project Architecture

- src/services/store.js – Central application store.
- src/lib/storage.js – Browser storage operations.
- src/services/ – Application services and business logic.
- src/services/analyticsService.js – Dashboard metrics, insights and alerts.
- src/services/selectors.js – Centre-scoped data views.
- src/components/ – Reusable UI components.
- public/ – Static assets.
